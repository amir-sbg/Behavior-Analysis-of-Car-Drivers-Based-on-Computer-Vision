## Suggested Future Additions

When the implementation is ready for public release, the repository can be extended with:

- A `src/` directory for modular perception and decision code.
- A `configs/` directory for model and runtime settings.
- A `notebooks/` directory for experiments or visual analysis.
- A reproducible environment file such as `environment.yml` or `requirements.txt`.
- A demo runner for processing synchronized inside-car and outside-car video streams.
- Evaluation notes covering detection quality, latency, robustness, and failure cases.

## Documentation Principle

Until code is added, this repository should remain honest and documentation-focused. It should describe what the system does, how the architecture is organized, and what the demonstrations show, without implying that a public implementation is already available.
